LadybugDB is an embedded columnar graph database with a Cypher query engine — DuckDB-style ergonomics for connected data. Zero-config single file, vectorized execution, with Postgres interop, lakehouse interop, and a surrounding ecosystem for analytics, visualization, agent filesystems, and RDF/SHACL.

## Ecosystem

One storage engine, several ways to reach it. Everything below reads and writes the same graph.

icebug — analytics notebooks · github

Columnar graph analytics that works directly on LadybugDB, Parquet, and Arrow — no export step. PageRank, components, community detection, paths.

bugscope — visualizer github

Lean, Rust-backed graph visualizer for exploring LadybugDB — built for large result sets, not slideware.

extensions — batteries included docs · registry

Rich extension system: adbc, postgres, duckdb, iceberg, delta, httpfs, json, fts, vector, algo, neo4j and more. INSTALL adbc; and query.

server — adbc · bolt adbc · bolt

Run embedded in-process, or serve it: ADBC for Arrow-native clients and Bolt for Neo4j-compatible drivers.

lakehouses new in 0.22.0 adbc docs · release notes

Query Snowflake and Databricks lakehouses live via ADBC — attach the warehouse and join it against your local graph.

pg_ladybug — postgres extension github

Runs the graph engine inside PostgreSQL. Cypher over your Postgres tables, native execution under the hood.

ladybug-fs — files for agents github

A filesystem view of the graph for agents that prefer writing text files: browse with ls, read with cat, mutate by rewriting files.

ontobug — rdf · shacl github

OWL ontologies, SHACL shapes, and RDF data stored as a Cypher property graph — validation on load, DDL constraining later writes.
